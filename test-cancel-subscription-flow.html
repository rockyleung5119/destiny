正确的取消订阅流程：

  1. 🔐 用户登录获取JWT token
  2. 🚫 前端调用取消订阅API（带认证头）
  3. 🔄 后端验证JWT token
  4. 📞 后端调用Stripe API设置 cancel_at_period_end=true
  5. 📡 Stripe发送 customer.subscription.updated webhook
  6. 💾 Webhook处理器更新D1数据库
  7. ⏰ 订阅周期结束时，Stripe发送 customer.subscription.deleted webhook
  8. 🚫 最终停用会员权限
